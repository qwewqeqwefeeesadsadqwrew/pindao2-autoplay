# 拼刀2 第三关 · 打开网页就自动玩

打开这个网址什么都不用点：游戏自己启动 → 自动进「拼刀2」第三关（没解锁就自己解锁）→
自动开打 → 结算面板一出现就自己按「再次挑战」→ 一直循环。

**每一局主角换一个形象**：青龙 / 大猩猩 / 哥斯拉 / 熊猫 / 吕布 / 猪八戒 六个里随机抽一个，
洗牌式（六个抽完再洗一遍），所以一轮里不会连着出同一个人。
想改名单：改 `autoplay.js` 里的 `SKIN_LIST` 一行（编号对照见仓库外的《形象节目单》）。

**背景音乐换成了《VENI VIDI VICI》（苏无名），首尾接上、无缝循环、一直转**；
游戏自带的音乐被按掉了，打斗音效照响。想换曲子：把音频文件放进本目录、
改 `bgm.js` 顶上的 `TUNE` 两行即可。

第一次打开会因为浏览器的「自动播放限制」没声音，页面上会有一个「点一下开声音」的小提示，
点一下（或按任意键）就有了——这是浏览器的规矩，任何网页都绕不过去。
想关掉换 BGM 这件事：网址后面加 `?bgm=0`（就回到游戏自己的音乐）；`?bgm=0.5` 调音量。

游戏本体（引擎/脚本/素材）全部从官方 CDN 现拉，一个字节都没改；
这个仓库里只有自动玩自己的代码（判断层 + 驱动 + 页面外壳）。

- `index.html` —— 页面外壳（`<base>` 指官方 CDN）
- `v12-data.js` / `v12-engine.js` / `v12-loop.js` —— 判断层
- `autoplay.js` —— 驱动（进关 / 接管 / 按「再次挑战」）
- `bgm.js` —— 背景音乐（按住游戏自带音乐 + 播我们的循环曲子）

调试：网址后面加 `?auto=0` 只开壳、不自动玩。

第一次打开要从 CDN 下素材（和官方原版一样，几十 MB），会慢一点，之后就快了。
